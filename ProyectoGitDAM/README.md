#Creación de repositorio en GitHub

#Descripción
Un programa que te saluda y si le escribes el número de commits que has hecho te dice cuantos commits ha hecho

#Lenguaje
El lenguaje que he utilizado ha sido java

#Ejecución
Dándole a play en la clase main

#Autor
Sergio Boluda Almero

#Documentación
1: Para crear una cuenta de github lo que he hecho ha sido iniciar sesión con cuenta de google
2: Para crear el repositorio remoto lo que he hecho ha sido darle al botoón de '+' en github y le he dado a "new repository"
3: Para subir el commit a github lo que he hecho ha sido darle a commit and push, le he puesto nombre, he puesto el enlace del repositorio, le he puesto el nombre de mi usuario de github y he generado  un nuevo token poniéndole 60 días de expiración y luego le he dado a pull para subirlo
